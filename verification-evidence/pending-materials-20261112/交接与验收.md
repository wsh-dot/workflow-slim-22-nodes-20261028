## 3. 启动方式

无需启动Java、Vue、Python Runner、Dify或模型服务。本轮是离线资料与资源交付。以下命令工作目录均为`E:/smartCost`，使用本机已有Python和jsonschema依赖。

```powershell
Set-Location -LiteralPath 'E:/smartCost'
python -B -X utf8 smart-cost-ai/tools/quota_rules/verify.py smart-cost-ai/resources/quota-rules/0903-20261112-v3
python -B -X utf8 -m unittest discover -s smart-cost-ai/tools/quota_rules -p test_package.py -v
```

重复构建仅复核复用相同版本；内容有变化会拒绝覆盖，需要新发行版本：

```powershell
python -B -X utf8 smart-cost-ai/tools/quota_rules/build.py
```

如需本机查看HTML预览，在环境允许本地监听时运行下列命令；保持终端运行，结束时按Ctrl+C。无需上传资料或开放外网端口。

```powershell
python -m http.server 18793 --bind 127.0.0.1 --directory E:/smartCost/verification-evidence/pending-materials-20261112/preview
```
