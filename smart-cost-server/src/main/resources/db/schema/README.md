# 数据库初始化脚本说明

## 文件职责

- `001__init_schema.sql`：删除并重建项目业务表和系统管理相关表，并创建索引、约束及字段注释。执行会清空这些表中的原有数据。
- `002__initial_data.sql`：清空并重新初始化系统管理所需的菜单、资源、权限、分类、字典和默认管理员数据。依赖 `001__init_schema.sql` 创建的表。
- `001__init_schema_erd.html`：数据库表结构关系图，仅用于查看，不需要在数据库中执行。

## 执行顺序

初始化数据库时，连接目标 PostgreSQL 数据库后，按以下顺序执行：

1. `001__init_schema.sql`
2. `002__initial_data.sql`

可使用 PostgreSQL 客户端（例如 `psql`）或数据库管理工具分别执行两个 SQL 文件。第二个脚本必须在第一个脚本成功完成后执行。两个脚本都会删除已有数据，只能用于初始化数据库。
